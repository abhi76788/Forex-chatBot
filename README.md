# Forex-chatBot
Chat bot for all forex related query

## Working prototype

A basic working prototype is available at:

`/home/runner/work/Forex-chatBot/Forex-chatBot/prototype/index.html`

### Run locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000/prototype/index.html`

### Prototype scope

- Forex Q&A for travelers (cash vs card, fees, ATM use, forex card, documents, safety)
- Rule-based chatbot logic for quick demonstration
- Simple web UI ready to be embedded later in a website
